portbind

Every flag, subcommand, and exit code. Same examples as the README.

Synopsis

portbind [options] [files-or-dirs...]
Tip: portbind --help prints this text in the terminal. portbind --version prints 1.0.0.

Flags and arguments

Flag / argumentMeaning
-h, --helpPrint detailed usage and exit 0.
-v, --versionPrint 1.0.0 and exit 0.
[files-or-dirs...]Targets to scan. Default: current directory. Skips node_modules, .git, dist, coverage.

Exit codes

CodeMeaning
0Both bind-all and PORT were found.
1One or both patterns missing.

Configuration

No configuration. A match for 0.0.0.0 anywhere plus a match for $PORT or the word PORT (word boundary) anywhere — they may live in different files.

Worked examples

Success path

Two files together satisfy the rule.

portbind ./app
{"ok":true,"hasBindAll":true,"hasPort":true}

Failure path

Only PORT is present.

portbind ./broken
{"ok":false,"hasBindAll":false,"hasPort":true}

Exit code is 1.
