portbind

Scan files for 0.0.0.0 and PORT or $PORT. Exit 0 only when both patterns exist.

1.00 / 1.0.0 branch main MIT Node.js >= 18

Overview

PaaS hosts like Render require listening on 0.0.0.0 and the provided PORT. portbind is a cheap static check you can run in CI so a merge cannot ship a localhost-only server.

Service authors targeting cloud hosts with ephemeral ports, and reviewers of Dockerfiles or Node servers.

Install

Install globally from Git, or run with Node from a clone. There are no extra dependencies.

npm install -g git+https://github.com/theworker02/portbind.git
portbind --help
node src/cli.js --help

Usage

Synopsis: portbind [options] [files-or-dirs...]

See the full CLI reference for every flag, exit code, and example.

portbind 1.00 (1.0.0)

Usage:
  portbind [options] [files-or-dirs...]

Scan UTF-8 files for:
  * 0.0.0.0          bind-all address
  * $PORT or PORT    port from the environment

Exit 0 only when BOTH are present (they may be in different files).

Options:
  -h, --help       Show this help
  -v, --version    Print 1.0.0

Examples:
  portbind
  portbind src/server.js
  portbind ./src ./bin

Examples

Success

Two files together satisfy the rule.

portbind ./app
{"ok":true,"hasBindAll":true,"hasPort":true}

Failure

Only PORT is present.

portbind ./broken
{"ok":false,"hasBindAll":false,"hasPort":true}

Exit code is 1.
